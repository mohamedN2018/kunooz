# 02 — جرد مميزات النشر والعرض (موجود / غير موجود)

تم التحقق من كل بند في الكود نفسه وبالاختبارات (`core/tests.py`)، ليس من أسماء الملفات.

## جدول المنشورات (`core.Post`)
موجود. جدول واحد لكل أنواع المحتوى، ونوع المحتوى يحدده **القسم** (`Category.category_type`):
كورسات / مقالات / منح وتدريبات / كتب وملخصات.

| الحقل | الوظيفة |
|---|---|
| title, slug (تلقائي ويدعم العربي) | العنوان والرابط |
| category, author | القسم والكاتب |
| content (محرر Jodit — بدل CKEditor 4) | المحتوى — يُنظَّف من السكربتات عند الحفظ والعرض، رفع صور آمن من داخل المحرر |
| image (قديم), featured_image, thumbnail (تلقائية) | الصور |
| excerpt | الملخص |
| link, link_delay | رابط خارجي بعدّاد تنازلي قبل فتحه |
| views | عدد المشاهدات |
| status, publish_date, created_at, updated_at | حالة ومواعيد النشر |
| seo_title, seo_description, seo_keywords | SEO |

## المميزات

| الميزة | الحالة | ملاحظات |
|---|---|---|
| إنشاء منشور من الموقع (`/create-post/`) | ✅ موجود ويعمل (مُختبَر) | للـ staff أو "محرر محتوى" فقط |

| **معاينة المسودة قبل النشر** | ✅ **أُضيف الآن** | `/preview-post/<id>/` للكاتب/المحرر/الـ staff فقط، `noindex` |

| عداد المشاهدات | ✅ موجود | |
| Sitemap | ✅ موجود — كان على example.com، **أُصلح** | |

| سجل التعديلات (Revisions) واسترجاع نسخة | ✅ **أُضيف** (جدول `PostRevision`) | نسخة تلقائية قبل كل تعديل (آخر 20)، قائمة "النسخ السابقة" أسفل صفحة التعديل، الاسترجاع POST فقط ويحفظ الحالية أولاً |
| حالة "قيد المراجعة" / موافقة رئيس التحرير | ✅ **أُضيف** | زر "إرسال للمراجعة"، قائمة `/staff/review/` مع زر نشر للـ staff. `REQUIRE_EDITOR_REVIEW=True` يمنع المحرر غير الـ staff من النشر المباشر (معطل افتراضياً للحفاظ على السلوك الحالي) |
| تاريخ انتهاء للمنح (deadline) | ✅ **أُضيف** | حقل "آخر موعد للتقديم"، يظهر في صفحة المنشور (متبقٍ X يوم / انتهى)، ترتيب المنح بالموعد فعلي، عدّاد "موعدها خلال 30 يوماً" حقيقي |
| التمييز بين "كتاب" و "ملخص" و "منحة"/"تدريب" | ⚠️ جزئي | يعتمد على وجود كلمة في العنوان/الكلمات المفتاحية، ليس حقلاً حقيقياً |
| النشرة البريدية | ❌ غير موجود | كان فورم شكلي بلا backend — أُزيل |
| صفحات السياسات (خصوصية/شروط) | ❌ غير موجود | الروابط كانت `#` — أُزيلت حتى يُكتب محتواها |


## الإعلانات (`advertisements`)
- لوحات الإدارة القديمة كانت تعتمد على `user.user_type` (غير موجود) وقوالب غير موجودة → لم يكن أحد يستطيع الدخول. **الآن**: روابط `/ads/dashboard/` وغيرها تحوّل الـ staff إلى لوحة Django للإعلانات (تعمل ومعرّبة).
- الحذف/التفعيل/الإجراءات الجماعية أصبحت POST فقط وللـ staff.
- `clear_ad_cache` كانت ترمي AttributeError (`cache.keys`) — أُصلحت. مسح الكاش لم يكن يعمل أصلاً (wildcard) — أُصلح.
- أي حفظ لإعلان بدأ بالفعل (حتى تسجيل الظهور/النقرة) كان يفشل بـ "تاريخ البدء في الماضي" — أُصلح.
- عرض الإعلانات في الموقع ما زال **معطلاً في القالب** (`base.html`) كما كان؛ تفعيله قرار تجاري.

## اللغة
- `LANGUAGE_CODE='ar'`: لوحة الإدارة ورسائل Django والتواريخ بالعربية، مع ملف تنسيق `kunooz/formats/ar` يُبقي الفاصلة العشرية نقطة (حتى لا تنكسر قيم CSS مثل `width: 12.5%`).
- لوحة Jazzmin لا تدعم RTL أصلاً → أُضيف `static/css/admin_rtl.css`.
